Apakah saya atau teman saya harus menginstal aplikasi? +

Tidak sama sekali. ScreenCast berjalan 100% di peramban web modern (Chrome, Edge, Safari, Firefox) tanpa ekstensi maupun aplikasi tambahan.

Bagaimana cara agar suara film terdengar jernih oleh penonton? +

Saat host menekan tombol "Pilih Layar & Mulai Siaran", centang opsi "Bagikan audio sistem" atau "Bagikan audio tab" pada jendela pilihan layar browser Anda.

Apakah foto strip Rollbooth tersimpan di server? +

Tidak pernah. Seluruh foto webcam dan tangkapan layar film diproses langsung di perangkat Anda menggunakan HTML5 Canvas 2D dan tidak pernah dikirim ke server mana pun.

Bisakah penonton bergabung dan menyalakan kamera dari HP? +

Sangat bisa! Penonton dapat membuka tautan ruang atau mengetik kode 6-digit dari Android maupun iPhone, menonton film secara layar penuh, serta mengaktifkan kamera depan untuk foto bersama.
